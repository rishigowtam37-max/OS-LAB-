# Operating Systems Lab

This repository contains the programs, shell scripts, and output files completed for the Operating Systems Laboratory.

## Experiments

| No. | Experiment | Programs / Concepts |
|-----|------------|---------------------|
| 1 | Installation of Windows Operating System | OS Installation |
| 2 | UNIX Commands and Shell Programming | UNIX Commands, Shell Scripts |
| 3 | System Calls | fork(), exit(), getpid(), wait(), close() |
| 4 | CPU Scheduling Algorithms | CPU Scheduling |
| 5 | Inter Process Communication (IPC) | Pipe |
| 6 | Semaphore Implementation | Mutual Exclusion, Semaphore |
| 7 | Banker's Algorithm | Deadlock Avoidance |
| 8 | Deadlock Detection Algorithm | Deadlock Detection |
| 9 | Threading | POSIX Threads (Pthreads) |
| 10 | Paging Technique | Logical to Physical Address Translation |
| 11 | Memory Allocation Methods | First Fit, Best Fit, Worst Fit |
| 12 | Page Replacement Algorithms | FIFO, LRU, Optimal |
| 13 | File Organization Techniques | Sequential, Direct (Random), Indexed |
| 14 | File Allocation Strategies | File Allocation Methods |
| 15 | Disk Scheduling Algorithms | Disk Scheduling |
